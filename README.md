# Android NAS (Server & Client)

> 把任何一台闲置的 Android 手机变成局域网 NAS，并通过完美的 MD3 客户端与 WebDAV 网络邻居进行跨设备管理。

## 🌟 核心特性矩阵

### 📱 服务端 (Server - 兼容 Android 2.2+)
- **双端口并发服务**：
  - `8080` 端口：提供极速 Web 网页端管理（内置 NanoHTTPD）。
  - `8081` 端口：提供标准 WebDAV 网络邻居（纯 Socket 原生实现）。
- **Web 网页端 (MD3)**：
  - 全区域拖拽上传（Drag & Drop），并带有真实的百分比进度条。
  - 支持多文件并发上传、文本在线编辑、图片在线预览、新建/递归删除文件夹。
- **协议全面兼容**：底层支持 HTTP `PUT` 方法，允许第三方客户端直接流式写入上传文件。
- **可视化排错**：若端口被占用或启动失败，App 首页会直接以红字显示错误原因，告别“无头无脑”连不上。
- **驻留能力**：前台服务常驻通知 + `START_STICKY` + `BOOT_COMPLETED` 开机自启。
- **安全防护**：严格的路径校验（`safeFile`），防止恶意客户端通过 `../` 访问系统私密文件。

### 🖥️ 客户端 (Client - 兼容 Android 5.0+)
- **设备中枢**：一级主页展示所有已保存设备，支持一键切换与滑动删除。
- **局域网扫描**：下拉刷新，多线程并发扫描网段内的 `8080` 端口，自动发现 NAS。
- **双协议智能路由**：
  - 连接自带服务端时，走 JSON 原生接口。
  - 连接外部 NAS（如群晖、威联通）时，走标准 WebDAV 协议。
- **文件操作**：支持悬浮按钮上传文件、下载到系统 `Download` 目录、查看文件属性。
- **现代 UI**：基于 Material Design 3，支持 Android 12+ 的 Monet 动态取色。
- **主题适配**：支持跟随系统、浅色、深色三种模式自由切换。

## 🚀 部署与使用指南

### 1. 部署服务端
1. 下载并安装 `android-nas-debug.apk` 到闲置手机上。
2. 打开 App 并授予存储权限。
3. 点击 **“启动服务”**。首页会显示当前局域网 IP 及对应的两个端口号（例如 `192.168.1.100:8080`）。
> **⚠️ 注意**：受 Android 3.1+ 安全机制限制，安装后**必须手动打开一次 App**，否则重启手机无法触发开机自启。

### 2. Web 网页端使用
在电脑或手机浏览器打开 `http://手机IP:8080`：
- **上传文件**：点击右下角 `+` 号选择文件，或直接将文件**拖拽**到网页顶部的虚线框内。
- **在线编辑**：点击 `.txt`、`.md`、`.json` 等文本文件的“编辑”按钮即可修改。
- **管理文件**：点击“新建文件夹”或“删除”按钮进行管理。

### 3. 挂载为本地网络驱动器 (WebDAV)
服务端原生支持 WebDAV 协议，你可以像使用 U 盘一样在电脑上访问手机文件：
- **Windows**：打开“此电脑” -> 右键 -> **映射网络驱动器** -> 输入 `http://手机IP:8081`。（若提示认证，直接留空或输入任意账号密码）。
- **macOS**：访达 -> 前往 -> **连接服务器** -> 输入 `http://手机IP:8081`。
- **Linux (Ubuntu)**：在文件管理器中选择“连接到服务器”，输入 `dav://手机IP:8081`。

### 4. 使用 Android 客户端
1. 安装 `nas-client-debug.apk` 并打开。
2. App 会自动扫描局域网内的设备。若未扫到，点击右下角 `+` 号手动添加：
   - **添加自研 NAS**：输入 IP 及 `8080` 端口。
   - **添加外部 NAS**：填写群晖等设备的 WebDAV 地址（如 `http://192.168.1.50:5005`）及账号密码。
3. 点击设备卡片即可进入文件管理，点击右下角 `+` 号即可上传本地文件。

## 📡 服务端 API 接口文档 (8080端口)

为方便二次开发，服务端提供了极简的 JSON API：

| 接口 | 方法 | 参数 | 说明 |
|---|---|---|---|
| `/api/list` | `GET` | `path` (当前路径) | 获取目录下的文件列表（返回 JSON） |
| `/api/download` | `GET` | `path` (文件路径) | 下载文件（二进制流） |
| `/api/preview` | `GET` | `path` (文件路径) | 获取文本文件内容 |
| `/api/upload` | `POST` | `path`, `file` | 网页端表单上传文件 |
| `/api/save` | `POST` | `path`, `content` | 保存在线编辑的文本内容 |
| `/api/mkdir` | `POST` | `path`, `name` | 新建文件夹 |
| `/api/delete` | `POST` | `path` | 递归删除文件或文件夹 |
| `/*` (任意路径) | `PUT` | 文件流 | 客户端 WebDAV 标准流式上传 |

## ❓ 常见问题排查 (FAQ)

1. **浏览器或客户端提示 `ERR_CONNECTION_REFUSED` (拒绝连接)？**
   - **端口冲突**：查看服务端 App 首页是否显示了**红色错误提示**。若提示端口被占用，请重启手机或关闭占用 8080/8081 的其他软件。
   - **系统防火墙**：部分手机（如华为、小米）有网络防火墙，需在系统设置中允许该 App 访问局域网。
   - **同机测试**：如果客户端与服务端在**同一台手机**上，请将连接地址改为 `127.0.0.1:8080`，部分安卓系统会拦截局域网 IP 自己连自己。
2. **客户端扫描不到服务端？**
   - 确保两台设备连接在**同一个 WiFi 下**。
   - 若路由器开启了“AP 隔离”（常见于公共网络），设备间无法互相访问，请关闭该功能或使用手机热点。
3. **为什么网页端上传大文件会失败？**
   - 受限于设备的运行内存和 NanoHTTPD 的表单解析机制，建议单文件不超过 1GB。如超过，建议使用客户端的 `PUT` 流式上传（无内存限制）。

## 🛠 架构说明与源码结构

本项目包含两个完全物理隔离的工程，互不干扰：

| 模块 | 目录 | 工具链 | 最低兼容 |
|---|---|---|---|
| 服务端 | `/` (根目录) | AGP 4.2.2, Gradle 6.7.1, JDK 8 | Android 2.2 (API 8) |
| 客户端 | `/client` | AGP 7.4.2, Gradle 7.5, JDK 11 | Android 5.0 (API 21) |

**GitHub Actions** 配置在 `.github/workflows/` 下，包含 `build.yml` (服务端) 和 `build-client.yml` (客户端)，推送至 `main` 分支即触发双端自动构建。
