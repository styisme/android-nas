# AI 生成声明

本项目（Android NAS）在开发过程中大量使用了大型语言模型（LLM）辅助生成代码与文档。

## AI 参与的部分

- **架构设计**：NanoHTTPD 嵌入式服务器、前台服务保活、开机自启广播。
- **业务逻辑**：文件浏览、下载、上传、本地文件操作、目录排序。
- **UI 代码**：本地管理界面布局、`BaseAdapter` 列表、Web 单页界面。
- **文档与脚本**：README、CHANGELOG、CONTRIBUTING、GitHub Actions 构建脚本、Python 一键生成脚本。

## 开发者负责的部分

- **需求定义**：提出“局域网网页管理 + 本地管理 + 开机自启 + 最低 Android 2.2”等需求。
- **功能验收**：在低版本设备和现代设备上真机测试。
- **Bug 定位**：解决兼容性、权限、构建失败等问题。
- **最终发布决策**：版本号、功能取舍、文档定稿。

## 已知风险

由于大量代码为 AI 生成：

- 边缘情况处理可能不完整（如极低内存设备上的保活、特殊 ROM 的存储权限行为）。
- 低版本 WebView / 浏览器对 `index.html` 中现代 JavaScript 的兼容性未完全覆盖。
- 上传大文件或高并发时的稳定性未做压力测试。
