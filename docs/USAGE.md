# Android NAS 详细使用说明书

本指南将手把手教你如何将这个项目部署到你的局域网，并玩转所有高级功能。

---

## 第一章：准备工作

1. **一台闲置的 Android 手机**（系统版本 Android 2.2 及以上，建议插着充电器并连接稳定的 Wi-Fi）。
2. **一台主力手机**（用于安装 Android 客户端）。
3. **一台电脑**（用于网页管理或映射网络驱动器，非必须）。
4. 确保所有设备连接在 **同一个局域网 (Wi-Fi)** 下。

---

## 第二章：服务端部署 (装在闲置手机上)

### 1. 安装与启动
- 去 GitHub Actions 下载最新的 `android-nas-server-xxx.apk`。
- 安装到闲置手机上，打开 App。
- **首次启动必须操作**：系统会弹出“忽略电池优化”的请求，请务必点击“允许”，否则手机息屏后 NAS 会断网。
- 点击首页的 **“启动服务”** 按钮，此时屏幕会显示 `网页管理: http://192.168.x.x:8080` 等信息。

### 2. 服务端驾驶舱（核心设置）
点击右上角菜单 -> **服务端控制中心**（驾驶舱）：
- **设备名称**：修改后，其他设备通过局域网扫描时看到的名称会变。
- **端口修改**：如果 `8080` 或 `8081` 被其他软件占用，可在此改为 `9090` 等。
- **密码修改**：修改管理员账号密码（默认 `admin/admin`）。建议修改，防止被他人乱看文件。
- **极寒省电模式**：如果你希望极致省电，勾选此项。开启后会自动降级 Wi-Fi 锁频率，并关闭高耗电的 LocalSend 与外网穿透，仅保留基础网页和 WebDAV。
- **流媒体/剪贴板开关**：按需开启或关闭。
- 修改完毕后点击“保存并重启服务”生效。

### 3. 内网穿透 (随时随地公网访问)
- 点击右上角菜单 -> **内网穿透**。
- **一键免费穿透**：点击启动后，App 会尝试连接多个全球免注册节点，成功后自动复制一个 `https://xxx` 的公网链接，发给任何人即可访问。
- **SSH 高级穿透**：如果你有自己的云服务器，选择此项填入公网 IP、SSH 账号密码与映射端口，实现更稳定的私密穿透。

## 第三章：Web 网页端使用

在电脑或手机浏览器打开 `http://手机IP:8080`，输入账号密码进入 MD3 管理界面。

### 1. 基础文件管理
- **拖拽上传**：直接把电脑上的文件拖入网页虚线框，进度条实时显示。
- **在线编辑**：点击 `.txt`、`.json` 等文件，可直接在网页高亮显示代码，并支持在线修改保存。
- **免密分享**：点击文件的“分享”，生成一个带 Token 的短链接，别人打开直接下载，无需密码。
- **其他操作**：支持新建文件夹、下载、删除、全局搜索、在线解压 ZIP。

### 2. 流媒体与剪贴板
- 如果上传了 `.mp4` 视频或 `.mp3` 音乐，网页端点击“播放”即可直接播放，支持拖动进度条。
- 点击右上角“📋 剪贴板”，你可以在这里输入文字，主力手机的客户端也能立刻获取。

## 第四章：Android 客户端使用 (装在主力手机)

### 1. 连接设备
- 打开客户端 App，点击右上角菜单选择“扫描局域网”，或下拉自动扫描。
- 也可以点击右下角 `+` 号：
  - **手动输入 IP**：填写服务端屏幕上的 IP 和端口。
  - **扫描二维码**：点击服务端的“连接二维码”直接扫码。
  - **添加外部 NAS (WebDAV)**：选择 WebDAV 协议，填入群晖等设备的地址。

### 2. 文件管理
- 点击设备卡片进入文件列表。
- **点击文件**：弹出 MD3 菜单（预览/播放、下载、重命名、删除、属性）。
- **长按文件**：进入多选模式，可一键批量删除。
- **右上角菜单**：可切换“网格视图/列表视图”，支持新建文件夹和全局搜索。
- **上传文件**：点击右下角悬浮 `+` 按钮，选择手机内的文件上传。

### 3. 相册自动备份
- 在主界面，点击设备卡片，选择 **“一键备份相册”**。
- App 会自动扫描你手机相册里的所有图片，全量传输到 NAS 的 `/Photos/` 目录（需授予相册权限）。

## 第五章：桌面端使用

- Windows 用户下载 `nas-client-windows-v*.exe`；Linux 用户下载 `nas-client-linux-v*`。
- 双击运行，输入 NAS 的 IP、端口、账号密码即可连接，支持文件浏览、上传、下载、重命名、删除。

## 第六章：超酷玩法

### 玩法一：电脑映射为网络驱动器 (WebDAV)
无需安装任何软件，把手机变成真正的 U 盘。
- **Windows**：右键“此电脑” -> 映射网络驱动器 -> 输入 `http://手机IP:8081` -> 输入账号密码。
- **macOS**：访达 -> 前往 -> 连接服务器 -> 输入 `http://手机IP:8081`。

### 玩法二：用 LocalSend 给 NAS 扔文件
你的 NAS 支持 LocalSend 协议，你不需要在 NAS 上安装 LocalSend！
1. 在你的电脑或其他手机上打开官方 LocalSend。
2. 此时会扫描到一个叫 `Android NAS` 的设备。
3. 向它发送文件，电脑会提示输入 PIN 码。
4. 输入 NAS 屏幕上显示的 PIN（默认 1234，可在控制中心修改）。
5. 文件秒传到手机的 `/Download/LocalSend/` 目录！

## 第七章：常见问题排查 (FAQ)

1. **网页打不开 / 拒绝连接？**
   - 检查服务端是否亮着“运行中”。
   - 检查是不是在同一 WiFi 下。
   - 检查路由器是否开启了“AP 隔离”。
2. **为什么息屏后下载就断了？**
   - 请务必在手机的系统设置里，把 NAS App 的后台电池策略设为“无限制”。
3. **LocalSend 搜不到 NAS？**
   - 去服务端驾驶舱检查 LocalSend 功能是否开启。
   - 检查是否开启了“极寒模式”（开启后会强制关闭）。
