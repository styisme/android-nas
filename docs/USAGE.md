# Android NAS 终极使用与运维指南

本指南是本项目的官方标准说明书。无论你是初次接触 NAS 的小白，还是想要榨干旧手机性能的极客，这里包含了从零部署、多模态远控、网络映射、跨端协同到极端故障排查的所有细节。

---

## 第一章：服务端（Server）深度部署与调优

服务端是整个十端生态的大脑，建议将其部署在一台屏幕完好（或碎屏但主板正常）的闲置 Android 手机上，并长期插电。

### 1.1 安装与基础权限授予
1. **安装应用**：前往 GitHub Releases 页面下载最新的 `android-nas-server-vX.Y.Z.apk`，安装到旧手机上。
2. **存储与通知权限**：首次打开 App 时，系统会要求“存储权限”和“通知权限”，务必点击允许，否则无法正常读取文件。
3. **所有文件访问权限（Android 11+ 必做）**：首次启动会自动弹窗提示，点击前往设置并开启 `MANAGE_EXTERNAL_STORAGE`。如果不给这个权限，NAS 连你手机相册里的照片都读不到。
4. **忽略电池优化**：弹出“后台保活提示”时，必须点击“去设置”并选择“允许”。若不小心点错，请去手机系统的 `设置 -> 应用管理 -> Android NAS -> 电池 -> 设为“无限制”`。

### 1.2 服务端驾驶舱（极致调优）
点击 App 右上角菜单，进入“NAS 驾驶舱”。界面现已重构为三个 Tab 页，所有设置保存后都会自动重启服务：
- **【基础】Tab**：修改设备名称；修改 Web (8080)、WebDAV (8081)、FTP (2121) 端口。
- **【服务】Tab**：一键开关 DLNA 投屏、网页流媒体、局域网剪贴板、LocalSend 接收端。并可修改 LocalSend 的 PIN 码（默认 1234）。
- **【高级】Tab**：
  - **🦅 全盘模式 (需 Root)**：开启后，网页端、FTP、WebDAV 均可直接访问 `/data`、`/system` 等底层目录。
  - **🎵 静音保活**：开启后，系统媒体中心会显示正在播放（通过伪造音频播放防止后台被系统查杀）。

### 1.3 多用户隔离系统
服务端底层新增了 SQLite 数据库 (`nas_core.db`)，全面支持多用户机制。
- **Admin 账号**：默认账号密码 `admin / admin`。拥有最高上帝视角，可访问全盘所有目录，并拥有网页端的“用户管理”权限。
- **Guest 账号**：默认账号密码 `guest / guest`。被严格锁定在 `/Public` 目录（或无权限）。
- **普通用户**：管理员在网页端创建的新用户。系统会自动为其分配独立物理目录（如 `/sdcard/Users/用户名`），普通用户的请求会被底层拦截器强制映射到其沙盒内，无法越权访问他人数据。
- **密码安全 (v4.4.0 强化)**：自 v4.4.0 起，所有密码（包括 Admin）在数据库中以 **SHA-256 加盐哈希** 存储，极大提升了数据库被拖库时的安全性。

### 1.4 高级系统特权 (Root/ADB) - 终极保活
在菜单中点击 `高级保活 (Root/ADB)`：
- **若手机已 Root**：直接点击【一键免死注入】。系统会在后台执行 `oom_score_adj=-1000`（获得比系统桌面还高的防杀优先级），并直接冻结各大厂商的流氓杀后台服务。
- **若未 Root**：你可以点击【复制 ADB 命令】，在电脑上连接手机后执行该命令，同样能获得 Doze 白名单和最高活跃度。
- **生成特权模块**：若已 Root，点击此按钮会生成一个 Magisk 模块。重启手机后，App 将变为系统级 `priv-app`，享受无限自启和最高广播优先级。

### 1.5 企业级安全防线 (v4.4.0 新增)
本项目在 v4.4.0 中实装了极为严苛的底层安全机制，可在网页端【系统设置】中配置：
- **防爆破 (Fail2Ban)**：默认开启。连续输错 5 次密码，系统会自动封禁该 IP 15 分钟，并在安全审计日志中记录。
- **IP 白名单**：支持通配符（如 `192.168.1.*`）。开启后，仅列表内的 IP 能够建立连接。**警告：请务必确认当前设备 IP 在白名单内，否则会将自己锁死。**
- **紧急安全码**：用于保护高危操作（如修改系统配置、执行 Web Shell、触发自毁）。
- **安全审计日志**：登录失败、文件删除、Shell 执行等敏感操作将持久化记录在 `AndroidNAS/audit.log` 中。

## 第二章：Web 网页端 (MD3) 与多模态远控中心

网页端是零安装的最快入口。请在电脑或平板的浏览器中访问 `http://手机IP:8080` 或 `https://手机IP:8080`（若开启了 HTTPS）。

### 2.1 系统控制台与鉴权
- 若开启了密码验证，浏览器会弹出原生输入框，输入默认的 `admin/admin` 即可。为防 Unicode 密码导致 Base64 编码崩溃，前端已改用安全的 UTF-8 编码逻辑。
- **系统设置**：点击右上角 `⋮` 图标，选择 `⚙️ 系统设置`。你可以在这里修改密码、配置端口、开关协议、配置 Webhook。
- **Webhook 推送配置**：支持填入 Telegram 机器人或企业微信群机器人的 Webhook 地址。配置后，文件上传事件等会实时推送到你的主力手机上。

### 2.2 PWA 添加到主屏幕
无需下载客户端，你的网页版就是原生的 App！
- 使用手机 Chrome 或 Edge 浏览器访问 NAS。
- 底部会自动弹出 **“添加到主屏幕”** 提示（或在浏览器菜单中手动点击）。
- 添加后，桌面会生成一个 NAS 图标。点击打开将全屏无地址栏运行，基于底层 `Service Worker`，支持部分静态资源的秒级加载。

### 2.3 多模态远程控制
这是本项目最硬核的功能，让你在电脑浏览器里直接控制手机。
1. **发起授权**：在服务端 App 菜单点击 **【请求录屏授权】**。
2. **打开远控**：在网页端点击右上角菜单 -> **【远程控制】**。
3. **鉴权机制**：自 v4.4.0 起，WebSocket 不再接受匿名连接。前端会自动从本地存储中获取 Token 并附加在 URL 中。非 `Admin` 角色无法建立连接。
4. **H264 丝滑模式**：默认状态，你可以看到 30fps 的高清画面。鼠标点击哪里，手机就点哪里。
5. **Root 截图模式**：如果未授权录屏，点击底部的 **【切换到截图流】**。系统会自动利用 Root 权限极速抓取画面，秒级刷新。

### 2.4 家庭私有云视界
- **📊 硬件仪表盘**：在网页右上角菜单点击“硬件仪表盘”。可实时查看服务端的 CPU 占用、内存使用、存储空间与电池电量（极客挂机必备，API 8 老设备自动降级显示）。
- **🖼️ 时光相册**：基于缩略图引擎，按时间倒序排列全盘照片，瀑布流秒加载，告别海量原图卡顿。
- **🎬 真实影视海报墙**：底层利用纯正则解析视频文件名，自动调用开源 API 获取真实海报、评分与简介。让你的电影文件夹秒变 Netflix 体验。
- **👥 用户管理**：管理员可在此查看现有用户，并动态添加新成员，自动分配独立目录。

### 2.5 文件流转与高级工具
- **大文件秒传与断点续传**：前端会自动计算文件 MD5，若服务端已有同 Hash 文件，直接 0 秒秒传完成。若没有，则切分为 2MB 分片进行传输，支持断点续传。
- **多选流式打包下载**：多选文件点击下载，服务端实时压成 ZIP 流推送，不占本地空间。
- **安全分享机制**：生成免密外链时，支持设置“提取码”与“有效期”。
- **在线解压与编辑**：支持 ZIP 在线解压；支持在线编辑文本并保存，服务端会自动备份原文件（带 `.bak` 时间戳）。
- **流媒体与剪贴板**：支持 `Range` 拖动播放；点击右上角 `📋 剪贴板`，跨设备复制文本。

### 2.6 安全面板与终极自毁
在设置面板的最底部，是 v4.4.0 新增的高危控制区：
- **在线设备与审计日志**：可以查看当前活跃连接，并调取最近的敏感操作记录。
- **☢️ 终极自毁 (Panic Wipe)**：这是特工级的核按钮。在点击后，你需要输入 NAS 管理员密码并经过多次确认。服务端会不可逆地摧毁所有存储文件，如果开启了 Root 模式，还会连同系统底层一起格式化并重启。**仅在废弃设备上测试！**

## 第三章：手机客户端 (Android Client)

手机客户端是你的随身控制中心。

### 3.1 局域网发现与连接
- 点击右上角的 🔍 图标，客户端会开启多线程并发探测 8080 端口。几秒内即可自动发现 NAS 并添加。
- 支持多协议：原生 JSON（极速）、WebDAV（通用）、FTP（兼容老旧设备）。

### 3.2 相册自动备份（增量比对）
1. 点击右上角菜单栏的 `相册自动备份`。
2. 首次使用会请求 `READ_MEDIA_IMAGES` 权限（Android 13+）。
3. **底层原理**：客户端先向服务端请求 `/Photos/` 目录的所有文件名，自动在服务端建好 `/Photos` 目录，再与手机相册比对，只上传新照片。

### 3.3 远控入口与分享外链
- **WebView 远控**：点击右上角菜单的 **【Web 远程管理】**，一键全屏打开网页端的终端和远控面板。
- **高级分享**：在文件列表菜单选择 **【分享外链】**，可以设置提取码，自动生成免密短链并直接调起系统分享面板。
- **一键投屏**：点击视频文件，选择“投屏到电视”，手机会通过 UDP 发送 Play 指令，电视端瞬间播放。

### 3.4 影视墙与安全控制 (v4.4.0 新增)
- **媒体网格视图**：在主页菜单中新增“时光相册”与“影视墙”。以三列瀑布流形式展示缩略图与真实海报。
- **双重验证自毁**：在系统设置的最底部。点击后需输入 NAS 密码，随后系统会拉起 Android 原生锁屏验证（指纹/密码）。验证通过才会触发服务端自毁。为防误触，手机端默认仅擦除外部存储，不开启 Root 系统格式化。

## 第四章：桌面端与 CLI 极客终端

### 4.1 桌面端 (Win/Linux)
基于纯原生 `Tkinter` 开发的扁平化 GUI。
- **系统托盘静默**：新增 `pystray` 支持。点击右上角关闭窗口时，程序会缩小至系统右下角托盘，保持后台剪贴板同步与监听。
- **全局搜索与剪贴板**：顶部新增全局实时搜索框，以及局域网剪贴板同步弹窗。
- **高级分享与秒传**：选中文件可生成带提取码的链接；上传大文件时自动启用 MD5 秒传校验与分片进度条。
- **多选上传与编辑**：支持多选文件并发上传，自带在线文本编辑与 ZIP 解压。

### 4.2 CLI 命令行端（极客专属）
1. 下载 `nas-cli-linux` 或 `nas-cli-windows.exe`。
2. 直接运行，首次运行会弹出彩色配置向导。
3. 再次运行，直接进入交互式极客终端：
   ```bash
   nas> ls                  # 列出当前目录
   nas> cd /Movies          # 切换目录 (支持 Tab 补全)
   nas> find mp4            # 全局搜索
   nas> get Inception.mp4   # 下载文件
   nas> put ./local.mp4     # 上传文件 (已实装 MD5 秒传与分片)
   nas> edit config.txt     # 调起系统默认编辑器编辑文件
   nas> share video.mp4 1234# 生成带提取码 1234 的免密分享链接
   nas> exec top            # 在服务端执行 Root Shell 命令
   ```

## 第七章：网络与协议互通（映射到电脑）

### 7.1 WebDAV 映射（Windows）
1. 右键“此电脑” -> “映射网络驱动器”。
2. 文件夹填写：`http://手机IP:8081`。
3. 输入账号密码。之后你的手机就会出现在“此电脑”里。

### 7.2 FTP 映射
1. 打开 Windows 资源管理器。
2. 在地址栏直接输入 `ftp://手机IP:2121`。
3. 回车，输入账号密码，即可进行拖拽传输。

### 7.3 使用 LocalSend 发送文件
你不需要在 NAS 上安装 LocalSend。
1. 在电脑打开官方 LocalSend 客户端。
2. 发现局域网名为 `Android NAS` 的设备。
3. 输入 PIN（默认 1234），文件会直接存入服务端的 `/Download/LocalSend/` 目录。

## 第八章：深度故障排查（Troubleshooting）

1. **提示“IP Blocked by Whitelist”或“Too many attempts”**：
   - 如果你在开启 IP 白名单后发现自己被锁，请用同一局域网的设备手动修改数据库或通过 App 强行重置应用数据。
   - 如果是因为输错密码触发了防爆破（15 分钟封禁），请等待封禁时间结束。
2. **安装时提示“未卸载”无法覆盖安装**：
   - v4.4.0 起包名已迁移至 `com.androidnas.all.*`。如果你刷了 Root 保活模块，它会 Hook 系统服务。请进入 Magisk 临时关闭保活模块并重启，或者使用 `pm uninstall --user 0 com.androidnas.all.server` 强行清理残留。
3. **远程控制黑屏 / 无法点击**：
   - 确保服务端已经点击了录屏授权，或者切换到了 Root 截图流。如果网页是 HTTPS 而 WebSocket 没连上，请确认前端是否正确切换到了 `wss://` 协议。
4. **自毁模式误触了怎么办？**：
   - 自毁是绝对不可逆的。如果是误操作且尚未勾选 Root 擦除，请立刻断开手机网络，强制关机，尝试用恢复软件找回未覆写的数据。
5. **全盘模式下无法修改系统文件**：
   - Android 的 `/system` 和 `/vendor` 默认是只读挂载的。即使在 Root 模式下，想要写入也需要在终端执行 `mount -o rw,remount /` 重新挂载读写权限。
