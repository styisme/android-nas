# Android NAS 终极使用与运维指南

本指南是本项目的官方标准说明书。无论你是初次接触 NAS 的小白，还是想要榨干旧手机性能的极客，这里包含了从零部署、多模态远控、网络映射、跨端协同到极端故障排查的所有细节。

---

## 第一章：服务端（Server）深度部署与调优

服务端是整个十端生态的大脑，建议将其部署在一台屏幕完好（或碎屏但主板正常）的闲置 Android 手机上，并长期插电。

### 1.1 安装与基础权限授予
1. **安装应用**：前往 GitHub Releases 页面下载最新的 `android-nas-server-vX.Y.Z.apk`，安装到旧手机上。
2. **存储与通知权限**：首次打开 App 时，系统会要求“存储权限”和“通知权限”，务必点击允许，否则无法正常读取文件。
3. **所有文件访问权限（Android 11+ 必做）**：首次启动会自动弹窗提示，点击前往设置并开启 `MANAGE_EXTERNAL_STORAGE`。如果不给这个权限，NAS 连你手机相册里的照片都读不到。
4. **忽略电池优化**：弹出“后台保活提示”时，必须点击“去设置”并选择“允许”。若不小心点错，请去手机系统的 `设置 -> 应用管理 -> Android NAS -> 电池 -> 设为“无限制”`。

### 1.2 服务端驾驶舱（极致调优）
点击 App 右上角菜单，进入“NAS 驾驶舱”。界面现已重构为三个 Tab 页，所有设置保存后都会自动重启服务：
- **【基础】Tab**：修改设备名称；修改 Web (8080)、WebDAV (8081)、FTP (2121) 端口。
- **【服务】Tab**：一键开关 DLNA 投屏、网页流媒体、局域网剪贴板、LocalSend 接收端。并可修改 LocalSend 的 PIN 码（默认 1234）。
- **【高级】Tab**：
  - **🦅 全盘模式 (需 Root)**：开启后，网页端、FTP、WebDAV 均可直接访问 `/data`、`/system` 等底层目录。
  - **🎵 静音保活**：开启后，系统媒体中心会显示正在播放（通过伪造音频播放防止后台被系统查杀）。

### 1.3 高级系统特权 (Root/ADB) - 终极保活
在菜单中点击 `高级保活 (Root/ADB)`：
- **若手机已 Root**：直接点击【一键免死注入】。系统会在后台执行 `oom_score_adj=-1000`（获得比系统桌面还高的防杀优先级），并直接冻结各大厂商的流氓杀后台服务（如小米的 `powerkeeper`、华为的 `powergenie`）。
- **若未 Root**：你可以点击【复制 ADB 命令】，在电脑上连接手机后执行该命令，同样能获得 Doze 白名单和最高活跃度。
- **生成特权模块**：若已 Root，点击此按钮会生成一个 Magisk 模块。重启手机后，App 将变为系统级 `priv-app`，享受无限自启和最高广播优先级。

### 1.4 极客玩法：Web Shell 终端
点击菜单中的 `高级保活`，或者直接在网页端点击右上角终端图标：
- 执行 `id` 返回 `uid=0(root)` 表示提权成功。
- 执行 `top` 查看系统进程，执行 `reboot` 让手机重启。
- **防误触机制**：服务端已强制拦截 `rm -rf /` 等极危指令，防止手滑删库。

## 第二章：Web 网页端 (MD3) 与多模态远控中心

网页端是零安装的最快入口。请在电脑或平板的浏览器中访问 `http://手机IP:8080`。

### 2.1 系统控制台与鉴权
- 若开启了密码验证，浏览器会弹出原生输入框，输入默认的 `admin/admin` 即可。
- **系统设置**：点击右上角 `⋮` 图标，选择 `⚙️ 系统设置`。你可以直接在网页上修改管理员密码、服务端口、开关各项协议。

### 2.2 多模态远程控制 (v4.0.0 核心玩法)
这是本项目最硬核的功能，让你在电脑浏览器里直接控制手机。
1. **发起授权**：在服务端 App 菜单点击 **【请求录屏授权】**。
2. **打开远控**：在网页端点击右上角菜单 -> **【远程控制】**。
3. **H264 丝滑模式**：默认状态，你可以看到 30fps 的高清画面。鼠标点击哪里，手机就点哪里；鼠标长按滑动，手机也会跟着滑动（基于无障碍或 Root 双引擎）。
4. **Root 截图模式**：如果未授权录屏，点击底部的 **【切换到截图流】**。系统会自动利用 Root 权限极速抓取画面，秒级刷新，适合用来远程帮长辈点个设置或查看状态。

### 2.3 文件与工具
- **多选上传**：点击右下角悬浮的 `+` 按钮，可一次性选择多个文件并发上传。
- **拖拽上传**：支持全区域文件拖拽，带真实百分比进度条。如果误拖了文件夹，会被拦截提示。
- **在线解压**：点击 `.zip` 文件右侧的 `⋮`，选择“解压”，服务端会直接解压至同目录。
- **全局搜索**：顶部搜索框输入关键词，全盘秒搜。
- **在线编辑**：点击 `.txt`、`.json` 等文本文件，可直接在网页内呼出 MD3 编辑器，修改后保存写回。

### 2.4 流媒体与局域网剪贴板
- **视频播放**：支持 `Range` 分片请求，随意拖动进度条，秒加载。
- **剪贴板**：点击右上角 `📋 剪贴板`，你在这里输入的文本会瞬间同步到所有客户端。

## 第三章：手机客户端 (Android Client)

手机客户端是你的随身控制中心。

### 3.1 局域网发现与连接
- 点击右上角的 🔍 图标，客户端会开启多线程并发探测 8080 端口。几秒内即可自动发现 NAS 并添加。
- 支持多协议：原生 JSON（极速）、WebDAV（通用）、FTP（兼容老旧设备）。

### 3.2 相册自动备份（增量比对）
1. 点击右上角菜单栏的 `相册自动备份`。
2. 首次使用会请求 `READ_MEDIA_IMAGES` 权限（Android 13+）。
3. **底层原理**：客户端先向服务端请求 `/Photos/` 目录的所有文件名，再与手机相册进行比对。只有 NAS 上没有的照片才会被上传。完全不用担心重复上传浪费流量。

### 3.3 远控入口与分享外链
- **WebView 远控**：点击右上角菜单的 **【Web 远程管理】**。它将全屏无缝加载网页端的终端和远控面板，让你在手机上也能自己控制自己。
- **分享外链**：在文件列表长按或点击菜单，选择 **【分享外链】**。系统会自动生成免密短链，并直接调起手机的分享面板，一键发给微信好友。
- **一键投屏**：点击视频文件，选择“投屏到电视”，手机会通过 UDP 发送 Play 指令，电视端瞬间播放。

## 第四章：桌面端与 CLI 极客终端

### 4.1 桌面端 (Win/Linux)
基于纯原生 `Tkinter` 开发的扁平化 GUI。
- **全局搜索与剪贴板**：顶部新增全局实时搜索框，以及局域网剪贴板同步弹窗。
- **一键复制外链**：选中文件点击底部按钮，免密短链会自动复制到电脑剪贴板。
- **多选上传与编辑**：支持多选文件并发上传，自带在线文本编辑与 ZIP 解压。

### 4.2 CLI 命令行端（极客专属）
1. 下载 `nas-cli-linux` 或 `nas-cli-windows.exe`。
2. 直接运行 `./nas-cli-linux`，首次运行会弹出彩色配置向导。
3. 再次运行，直接进入交互式极客终端：
   ```bash
   nas> ls                  # 列出当前目录
   nas> cd /Movies          # 切换目录 (支持 Tab 补全)
   nas> find mp4            # 全局搜索
   nas> get Inception.mp4   # 下载文件
   nas> put ./local.mp4     # 上传文件
   nas> edit config.txt     # 调起系统默认编辑器编辑文件
   nas> share video.mp4     # 生成免密分享链接
   nas> exec top            # 在服务端执行 Root Shell 命令
   ```

- **苹果 / 鸿蒙端**：采用原生的 SwiftUI 与 ArkTS 编写。虽然操作系统的生态封闭，但它们同样内置了服务端的全部核心 API。支持全盘搜索、剪贴板双向同步，并能通过系统级 API 跳转外部浏览器体验远控。
- **微信小程序端**：免安装即用。支持全盘文件搜索、局域网剪贴板浮层。最实用的是 **【免密分享链接自动复制】**，非常适合把文件直接甩给微信群里的朋友。

## 第六章：TV 电视端 & 手表端

- **TV 端**：专为老旧电视盒子打造。采用 Leanback 卡片流，使用遥控器移动时，卡片会呈现 **1.1 倍放大与高亮边框动画**。输入文字时，使用虚拟全键盘边打边搜。

## 第七章：网络与协议互通（映射到电脑）

### 7.1 WebDAV 映射（Windows）
1. 右键“此电脑” -> “映射网络驱动器”。
2. 文件夹填写：`http://手机IP:8081`。
3. 输入账号密码 `admin` / `admin`。之后你的手机就会出现在“此电脑”里，像本地 U 盘一样操作。

### 7.2 FTP 映射
1. 打开 Windows 资源管理器。
2. 在地址栏直接输入 `ftp://手机IP:2121`。
3. 回车，输入账号密码，即可进行拖拽传输。

### 7.3 使用 LocalSend 发送文件
你不需要在 NAS 上安装 LocalSend。
1. 在电脑打开官方 LocalSend 客户端。
2. 发现局域网名为 `Android NAS` 的设备。
3. 输入 PIN（默认 1234），文件会直接存入服务端的 `/Download/LocalSend/` 目录。

## 第九章：深度故障排查（Troubleshooting）

1. **安装时提示“未卸载”无法覆盖安装**：
   - 如果你刷了 Root 保活模块，它会 Hook 系统服务。请进入 Magisk 临时关闭保活模块并重启，或者使用 `pm uninstall --user 0 <包名>` 强行清理残留。
2. **网页端报错 `ERR_CONNECTION_REFUSED`**：
   - 检查服务端 App 首页是否亮着绿灯。若是红字，说明端口冲突，请在控制中心更换端口。
3. **远程控制黑屏 / 无法点击**：
   - 确保服务端已经点击了录屏授权，或者切换到了 Root 截图流。同时确保在网页上操作时，没有被浏览器的混合内容（HTTPS 与 HTTP）拦截。
4. **跨端投屏搜不到电视**：
   - 检查路由器是否开启了“AP 隔离”（导致 UDP 广播失败）。确认电视端 App 是否在后台被杀。
5. **全盘模式下无法修改系统文件**：
   - Android 的 `/system` 和 `/vendor` 默认是只读挂载的。即使在 Root 模式下，想要写入也需要在终端执行 `mount -o rw,remount /` 重新挂载读写权限，极具风险，请谨慎操作。
