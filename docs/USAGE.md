# Android NAS 终极使用与运维指南

本指南是本项目的官方标准说明书。无论你是初次接触 NAS 的小白，还是想要榨干旧手机性能的极客，这里包含了从零部署、网络映射、跨端协同到极端故障排查的所有细节。

---

## 第一章：服务端（Server）部署与深度调优

服务端是整个生态的大脑，我们建议将其部署在屏幕完好或哪怕碎屏但主板正常的闲置 Android 手机上。

### 1.1 安装与环境准备
1. **下载与安装**：从 GitHub Actions 获取最新构建的 `app-debug.apk`，通过数据线或局域网发送到旧手机上进行安装。
2. **权限授予**：首次打开 App 时，系统会要求“存储权限”和“通知权限”，请务必允许。
3. **忽略电池优化**：这是最关键的一步。Android 6.0 及以上系统有 Doze 模式（打盹模式），会在息屏后强制休眠 App，导致 NAS 断连。首次启动 App 时，系统会自动弹窗提示“忽略电池优化”，请务必点击“允许”。如果误点取消，请在手机的 `设置 -> 应用管理 -> Android NAS -> 电池 -> 无限制` 中手动更改。
4. **启动服务**：点击首页巨大的“启动服务”按钮，此时屏幕上会显示当前局域网 IP 和各个端口的分配情况。

### 1.2 服务端驾驶舱（极致调优）
点击右上角菜单，进入“NAS 驾驶舱”。这是一个专门为极客准备的控制中心：
- **设备名称**：修改后，局域网内其它设备扫描到的名称会变。
- **端口修改**：
  - Web 端口（默认 8080）：如果与路由器冲突，可改为 9090 等。
  - WebDAV 端口（默认 8081）：用于映射网络驱动器。
  - FTP 端口（默认 2121）：用于老电视或老电脑访问。
- **极寒省电模式（Aggressive Low Power）**：
  - **原理**：当开启时，App 会将 `WifiManager.WifiLock` 从 `HIGH_PERF`（高性能模式）降级为 `FULL`（普通模式），允许 Wi-Fi 芯片在空闲时休眠。同时，强行切断外网穿透的 SSH 长连接，并停止 LocalSend 的 UDP 组播接收和 DLNA 的广播服务。
  - **取舍**：极寒模式下，你将获得极致的待机功耗，但代价是：只能通过局域网 IP 访问，无法投屏，无法接收 LocalSend 传输。适合夜间或长期无人值守时开启。
- **流媒体/剪贴板开关**：关闭流媒体后，服务端将拒绝响应 `Range` 分片请求，视频只能下载不能预览；关闭剪贴板后，`/api/clipboard` 返回 403。

## 第二章：Web 网页端 (MD3) 全方位解析

网页端是零安装的最快入口。请在电脑或平板的浏览器（推荐 Chrome / Edge / Safari）中访问 `http://手机IP:8080`。如果开启了密码验证，浏览器会弹出原生的 Basic Auth 弹窗，请输入默认的 `admin / admin`。

### 2.1 文件与目录管理
- **拖拽上传**：全区域支持拖拽。你可以直接把 10GB 的电影拖进网页，进度条会实时显示百分比。
- **多文件上传**：点击右下角悬浮的 `+` 按钮，支持一次性选择多个文件进行并发上传。
- **新建文件夹**：点击左侧面板的“新建文件夹”按钮。
- **在线解压**：上传一个 `.zip` 文件，点击对应的“解压”按钮，服务端会自动调用原生 `java.util.zip` 库进行解压，防路径穿越校验已开启。

### 2.2 流媒体与在线编辑
- **代码编辑**：点击 `.json`、`.txt` 或 `.java` 文件，网页会弹出一个 MD3 风格的弹窗，内置 `highlight.js` 语法高亮。修改后点击保存，会直接写回服务端。
- **视频播放**：点击 `.mp4` 视频右侧的“播放”按钮，网页会呼出原生 `<video>` 播放器。由于服务端支持 `HTTP 206 Partial Content` 和 `Range` 请求头，你可以随意拖动进度条，秒加载。
- **图片预览**：点击 `.jpg` 会以 `<img>` 标签直接渲染。

### 2.3 局域网剪贴板与免密分享
- **剪贴板**：点击右上角“📋 剪贴板”，输入文字并保存。此时你在手机客户端点击“剪贴板”，就能直接获取这段文字。
- **免密分享**：点击文件的“分享”按钮，后端会生成一个 UUID Token 短链，形如 `/share/abcd1234`。你可以把这个链接发给任何不在局域网的人，他直接点击就能下载文件，无需输入你的管理密码。

## 第三章：手机客户端（Android Client）

### 3.1 添加设备与多协议支持
点击客户端右下角的 `+`，你可以添加三种类型的设备：
1. **自家 NAS（原生接口）**：填写 IP 和 8080 端口，走极速 JSON 接口。
2. **WebDAV（外部 NAS）**：如果你有群晖或威联通，填入 WebDAV 地址（如 `http://192.168.1.50:5005`），客户端会自动解析 XML 返回树。
3. **FTP（老式服务器）**：填入老式服务器的 IP 和 2121 端口。

### 3.2 相册自动备份
在主界面点击你的自家 NAS 卡片，选择 **“一键备份相册”**。
- 客户端会请求 `READ_MEDIA_IMAGES` 权限（Android 13+），然后扫描本机所有的照片，通过后台线程逐个通过 `PUT /Photos/` 接口上传到服务端。目前暂未实现“跳过已存在”的校验，每次备份会全量覆盖。

### 3.3 跨端协同（黑科技）
- **下发配置**：点击右上角菜单“发送配置到电视”。手机会通过 UDP 广播在局域网寻找 TV 端的 `8090` 端口，找到后，将当前 NAS 的 IP、账号、密码通过 HTTP POST 发送过去。
- **一键投屏**：在文件列表中点击视频，选择“投屏到电视”。手机会向 TV 端发送一个 `GET /play?url=xxx` 的请求，TV 端会立刻黑屏全屏播放。

## 第四章：TV 电视端 & 手表端

### 4.1 TV 端交互逻辑
- TV 端采用“左右分栏布局”，左边是菜单，右边是文件列表。
- 所有焦点切换依赖遥控器的 `上下左右`，确认键为 `Enter`。
- 输入文字是电视端的痛点。我们做了“B站同款虚拟键盘”。用遥控器敲击字母，进行“边打边搜”。

### 4.2 手表端操作
- 手表端支持圆盘与方盘，采用 MD3 卡片风格。
- 长按屏幕可返回上一级目录。
- 支持多协议添加设备，但输入密码非常痛苦，所以强烈建议先让手机端下发配置到电视，手表再通过 UDP 同步电视的配置。手表点击视频，也会向电视发送投屏指令。

## 第五章：环境与协议互通（映射到电脑）

### 5.1 WebDAV 映射（Windows）
1. 右键“此电脑” -> “映射网络驱动器”。
2. 文件夹填写：`http://手机IP:8081`。
3. 输入账号密码 `admin` / `admin`。之后你的手机就会出现在“此电脑”里，像本地 U 盘一样操作。

### 5.2 FTP 映射
1. 打开 Windows 资源管理器。
2. 在地址栏直接输入 `ftp://手机IP:2121`。
3. 回车，输入账号密码，即可进行拖拽传输。

### 5.3 使用 LocalSend 发送文件
你不需要在 NAS 上安装 LocalSend。
1. 在电脑打开官方 LocalSend。
2. 发现局域网名为 `Android NAS` 的设备。
3. 输入 PIN（默认 1234），文件直接存入 `/Download/LocalSend/` 目录。

## 第六章：深度故障排查（Troubleshooting）

1. **报错 `ERR_CONNECTION_REFUSED`**：
   - 检查服务端 App 首页是否亮着绿灯。若是红字，说明端口冲突，请在控制中心更换端口。
   - 检查是不是用旧手机的局域网 IP 访问了自己（127.0.0.1），如果是同机测试，请改用 `http://127.0.0.1:8080`。
2. **LocalSend 搜不到设备**：
   - 有些路由器开启了“AP 隔离”，导致 UDP 组播被丢弃。
   - 检查是否在控制中心开启了“极寒模式”。
3. **极寒模式导致文件传到一半断了**：
   - 极寒模式降级了 Wi-Fi 锁，系统可能会在闲置 30 秒后断开连接。请关闭极寒模式再传大文件。
4. **Android 13 相册备份闪退**：
   - 请检查 `AndroidManifest.xml` 里是否声明了 `READ_MEDIA_IMAGES` 权限，并在系统设置中手动授权。

*(更多深度排查请查阅 GitHub Issues 或提交 PR 指正。)*
